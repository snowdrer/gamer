# Galiformes

Galiformes é um projeto de jogo indie que mistura criatividade, aventura e humor.
O projeto está em desenvolvimento e tem como objetivo criar uma experiência divertida, com personagens marcantes e uma ideia própria.

Este repositório será usado para compartilhar o desenvolvimento do jogo, suas novidades e futuras atualizações.
